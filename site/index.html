A macOS terminal for running many coding agents at once.

Named workspaces, one session per agent, a status glyph that says who needs you, and a local control socket the agents use to drive the terminal themselves. Native, on the Ghostty engine.

Download .dmg brew install --cask ryuldashev/agx/agx

Apple Silicon · macOS 14+ · signed and notarized · MIT · installs beside agterm

Set up in five steps

  1. Open the DMG and drag agx.app into Applications with the Finder. Don't launch it from the DMG: macOS then runs it from a random translocated path, and the paths the installers below bake in go dead on the next launch. Homebrew does this for you.
  2. Help ▸ Install Command Line Tool…Puts agtermctl and agx on your PATH. One admin prompt.
  3. Help ▸ Install Agent Status Hooks…Claude Code reports active / blocked / done onto its session row, and every session opened inside agx starts with a description of the UI in its context.
  4. Settings ▸ Agents ▸ ConnectThe list probes your Mac for Claude Code, Codex, Gemini and the rest. One click connects the one you use.
  5. Right-click a workspace ▸ Workspace Defaults…A directory and an agent per workspace. A new tab in mars lands in ~/mars with Claude already running.

What an agent sees when it starts

Every Claude Code session inside agx gets this on its first turn, from agx context. The agent knows which pane it is, what else is running, and which commands change the UI.

me: "✳ Claude Code" [B97C249F] · workspace mars · pane left · cwd /Users/you/mars · running claude

you can drive this UI:
  agx spawn --brief "<task>" --name "<title>" [--workspace-name W] [--cwd PATH]
  agx schedule add --at "tomorrow 09:00" --brief "<task>"
  agx run "<shell cmd>"                runs in your own side pane, returns output + exit code
  agtermctl session text --target <id>  read another session
  agtermctl notify "<body>"            desktop notification

agx CLI

agx context [--json]
Self-description of the UI for an in-pane agent: who am I, what does the user see, what can I do.
agx spawn --brief "…" --name "…"
Creates an agent session and hands it the brief as its first message. A full peer session, visible in the sidebar, no typing race.
agx schedule add --at "+2h" --brief "…"
The app itself opens the session at that time. Survives restart; a job missed by more than 24h is parked, not fired late.
agx run "cmd" [--pane split]
Runs a finite command in the session's side pane and returns output and exit code.
agx usage [--json]
Model, context and cost across every open session, plus account pools.
agtermctl …
The full control API: sessions, workspaces, splits, overlays, picker, notifications, events. Command reference.

What agx adds to agterm

Connected agentsSettings ▸ Agents lists local agent CLIs and finds the ones installed on this Mac, including the paths launchd hides from GUI apps.
Workspace defaultsDirectory and agent per workspace, from the sidebar or agtermctl workspace defaults.
Durable agent panesEach agent runs under a detached session server (abduco). Quit, relaunch or crash agx and the same process reattaches with its context and unfinished turn.
Scheduled sessionsschedule add / list / cancel / run. Control-native, persisted in the state dir, fires on launch and on display wake.
Reopen brings the agent back⌘⇧T on a closed Claude session restores the conversation, not a bare shell.
⌥ names the chromeHold ⌥ and every visible control shows its token and shortcut, so an agent can be told which button by name.
Action journaljournal.jsonl in the state dir records chords, palette actions, control requests and state changes. "Who closed that pane" is a tail, not a guess.
agx CLI + SessionStart hooksBundled and installed from the Help menu, so a fresh Mac gets the same agent experience as the author's.

Everything else is agterm: the workspace model, splits, scratch and overlays, the dashboard, the keymap editor, the control API. What diverges and how upstream is rebased in is in FORK.md.

Notes

Requirements. The agx CLI is a python3 script; macOS provides python3 with the Xcode Command Line Tools. The hooks are for Claude Code; Codex, Pi and OpenCode get status hooks only.

Where things live. State, socket and journal: ~/Library/Application Support/agx. Keymap and config: ~/.config/agx. Agent hooks: ~/.config/agx/agent-status and a marker-guarded block in ~/.claude/settings.json. Uninstall removes those and nothing else.

Side by side. Bundle id uz.marshub.agx, own state and socket. An existing agterm install is not touched.

agx is a fork of umputun/agterm, MIT. Changelog Issues Mars IT School, Tashkent.
