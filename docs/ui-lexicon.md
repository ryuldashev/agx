# Словарь интерфейса agx

Общий язык для фидбэка по кнопкам. Правило: **элемент называем его токеном** (левая колонка),
а не «та кнопка справа сверху».

**Подсмотреть токен прямо в приложении: зажать ⌥** — под титлбаром всплывает панель-шпаргалка
со всеми видимыми контролами (иконка · токен · горячая клавиша). Отпустил — исчезла. Панель
показывает ровно то, что сейчас на экране: скрытые через Settings ▸ Interface кнопки в неё не
попадают. Для скриншота панели (руками её не снять — шорткат снимка занимает ту же клавиатуру):
`open --env AGX_HINTS_ALWAYS=1 /Applications/agx.app` — панель залипает на весь запуск.

## Формат фидбэка

```
<id> · <состояние, если есть> : <что сделал> → ожидал <X>, получил <Y>
```

Примеры:
- `split-toggle · both : клик → ожидал, что скроется правая панель, скрылась левая`
- `scratch-toggle : клик дважды → скретч не возвращается`
- `add-session : клик в воркспейсе mars → открылся шелл, а не Claude`

Состояние нужно только там, где кнопка многосостоянийная (`split-toggle`, `focus-filter-toggle`,
`flagged-view-toggle`, `scratch-toggle`). Если не уверен в состоянии — не пиши, я посмотрю сам:
`agtermctl tree --json` показывает живое дерево, а у `split-toggle` состояние читается прямо из UI.

## Титлбар (слева направо)

| токен (⌥) | что это | клавиша | id в коде |
|---|---|---|---|
| `sidebar` | показать/скрыть сайдбар | ⌃⌘S | `sidebar-toggle-button` |
| `recent` | попап недавних сессий | ⌃⇥ | `recent-sessions-button` |
| `bell` | сессии, требующие внимания (появляется, только когда есть такие) | ⌃⇧I | `attention-button` |
| `zoom` | развернуть текущую панель на всё окно | ⌘⇧⏎ | `zoom-toggle` |
| `split` | сплит сессии (см. ниже) | ⌘D / ⌘⇧D — горизонтальный | `split-toggle` |
| `dash` | сетка всех живых сессий | ⌘⇧G | `dashboard-toggle-button` |
| `quick` | быстрый терминал поверх окна | ⌃` | `quick-terminal-toggle` |

## Сайдбар

| токен (⌥) | что это | клавиша | id в коде |
|---|---|---|---|
| `workspace+` | новый воркспейс | ⌘⇧N | `new-workspace` |
| `session+` | новая сессия в текущем воркспейсе | ⌘N | `add-session` |
| `filter` | фильтр: только «сфокусированные» воркспейсы | — | `focus-filter-toggle` |
| `flagged` | режим сайдбара: только помеченные сессии (⌘⇧F — пометить) | — | `flagged-view-toggle` |
| `private` / 🔒 | приватная сессия: не сохраняется, транскрипт стирается при закрытии (⌘⇧P — новая; контекстное меню строки — переключить) | ⌘⇧P | `new-private-session` |

Строки сайдбара: **workspace row** и **session row**. Адресуем по имени (`воркспейс mars`,
`сессия ✳ Claude Code`) или по id из `agtermctl tree`.

Скретч-терминала в титлбаре больше нет (кнопку заменил `zoom`): сам скретч жив и открывается ⌘J,
через палитру ⌃P и `agtermctl session scratch`.

## Панели одной сессии

- **main pane** — основная панель (левая или верхняя). В control API — `--pane left`. Фокус: ⌃1.
- **split pane** — вторая панель (правая или нижняя). `--pane right`. Фокус: ⌃2.
- **scratch** — третий шелл, накрывает сессию целиком (`scratch-toggle`, ⌘J).
- **quick terminal** — отдельная панель поверх всего окна (`quick-terminal-toggle`, ⌃`).
- **dashboard** — оверлей-сетка живых сессий (`dashboard-toggle-button`, ⌘⇧G).
- **terminal zoom** — панель на весь экран (⌘⇧⏎).

Порядок «накрывашек»: quick terminal и dashboard — над окном, scratch — над сессией,
zoom — над панелью. Пока накрывашка видна, `split-toggle` сначала снимает её, а не трогает панели.

## split-toggle: три состояния, не два

Кнопка не бинарная. У сессии есть флаг «сплит существует» (`hasSplit`) и отдельный
«сплит показан» (`isSplit`). Отсюда цикл:

| состояние | иконка | что делает клик |
|---|---|---|
| `none` | пустой контур 2×1 | **создаёт** второй шелл, показывает обе панели, **фокус уходит в новую панель** |
| `both` | обе половины залиты | **прячет** сплит: обе панели живы, на весь экран остаётся **main pane** |
| `left` / `right` / `top` / `bottom` | залита одна половина — та, что видна | показывает обе панели снова |

Так это работает **в форке** (изменено 2026-08-25). До правки прятанье шло за фокусом: первый клик
создаёт панель и переводит в неё фокус, поэтому второй клик оставлял на экране именно новый терминал,
а панель с агентом уезжала под спуд — при том что тултип обещал «Hide split». Теперь клик по кнопке
(и ⌘D) всегда оставляет main pane, как и написано на кнопке.

Zoom «разверни ту панель, в которой я сижу» никуда не делся:
- `⌃1` / `⌃2` на **скрытом** сплите переключают, какая из панелей развёрнута;
- `agtermctl session split --hide` по-прежнему разворачивает панель в фокусе (скриптам не сломали);
- ⌘⇧⏎ — полноэкранный zoom панели.

Ничего не закрывается: реально убить вторую панель может только её собственный `exit` или
Close Split из палитры (⌃P).

## Как я смотрю состояние сам

```bash
AGX=/Applications/agx.app/Contents/MacOS/agtermctl
export AGTERM_SOCKET="$HOME/Library/Application Support/agx/agx.sock"
$AGX tree --json     # воркспейсы, сессии, панели, cwd, что запущено
$AGX keymap list     # актуальные горячие клавиши
```
